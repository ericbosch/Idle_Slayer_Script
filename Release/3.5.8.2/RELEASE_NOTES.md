# Idle Runner 3.5.8.2

This hotfix corrects update checks and includes the final Circle Portals color calibrations.

## Fixed

- Read the complete GitHub release tag instead of assuming a five-character version.
- Preserve network errors while decoding the GitHub API response.
- Prevent the current version from being reported as outdated.
- Use the exact observed Modern City portal color.
- Detect the current portal world on its color strip and reject ambiguous matches.

## Updating

Use the **Update** button to check the latest release, then download the attached ZIP from GitHub Releases.
